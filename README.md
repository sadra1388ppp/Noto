# SimpleReminders

A small Windows productivity and reminders app built with C# and .NET 10 WPF.

## Features

- Add reminders with optional due dates
- Complete and uncomplete reminders
- Delete reminders
- Search reminders
- Create custom reminder lists
- Right-click custom lists to delete them
- Local JSON persistence
- XP and level progression
- Coins earned from productivity
- Achievements with coin and XP rewards
- In-app store
- Buy and equip themes with coins
- Extensible reward/store catalog

## Run

```powershell
git clone https://github.com/sadra1388ppp/SimpleReminders.git
cd SimpleReminders
dotnet run
```
