# SimpleReminders

A small Windows reminders app built with C# and .NET 10 WPF.

## Current MVP

- Add reminders
- Optional due dates
- Complete and uncomplete reminders
- Delete reminders
- Search reminders
- Create custom lists
- Local JSON persistence

## Run locally

```powershell
git clone https://github.com/sadra1388ppp/SimpleReminders.git
cd SimpleReminders
dotnet run
```
